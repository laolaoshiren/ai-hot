Claude Science 是 Anthropic 的最新旗舰产品

原始标题：Analysis: Claude Science is Anthropic’s newest flagship product
⚡ 一句话看懂：在周二为制药公司高管、生物技术创始人和研究人员举办的活动中，Anthropic 宣布推出 Claude Science…

在周二为制药公司高管、生物技术创始人和研究人员举办的活动中，Anthropic 宣布推出 Claude Science，这是一款重要的新产品，旨在支持科学研究，就像 Claude Code 支持软件工程一样。

与 Claude Code 一样，Claude Science 可以在得到简洁、高级指令的情况下自主开展有意义的工作，并且它可以使用使其对计算生物学和药物开发研究特别有用的工具。

除了推出和预览 Claude Science（现已向所有付费 Claude 订户开放）外，Anthropic 还宣布将使用该产品开展自己的一些针对罕见、被忽视疾病的药物研究。

这并不是 Anthropic 首次涉足科学人工智能领域。

10 月，该公司发布了“Claude for Life Sciences”标题下的插件，帮助 Claude 使用科学软件和数据库。

但与早期版本不同的是，Claude Science 是一款功能齐全的独立产品。

Anthropic 决定将 Claude Science 提升到与 Claude Code 和 Claude Cowork 相同的级别，这表明该公司正在非常认真地对待人工智能的科学应用，或者至少希望给人留下这样的印象。

Anthropic 生命科学主管 Eric Kauderer-Abrams 表示：“它与 Claude Code 和 Claude Cowork 齐名，成为我们发布的下一个真正重要的产品，这表明这对我们的使命有多么重要。

” “我们的使命是开发为人类长期福祉服务的人工智能，我们相信迄今为止实现这一目标的最大机会是在生命科学领域。

” 在过去的十年里，谷歌 DeepMind 一直是科学人工智能领域的先锋。

首席执行官 Demis Hassabis 和研究员 John Jumper 因其在公司 AlphaFold 模型上的工作而获得了诺贝尔化学奖，DeepMind 还为气象学、材料科学和其他各种学科做出了重大贡献。

但在过去的几个月里，快速推进的人工智能前沿进展似乎让 DeepMind 望尘莫及。

编码已成为法学硕士最赚钱的用例，而在编码方面，DeepMind 却陷入了追赶的困境。

Anthropic 完全有能力继承 DeepMind 的科学衣钵。

与哈萨比斯一样，Anthropic 首席执行官达里奥·阿莫迪 (Dario Amodei) 也是一名博士科学家，而 OpenAI 首席执行官萨姆·奥尔特曼 (Sam Altman) 则是一位彻头彻尾的商人。

许多科学家已经成为 Claude Code 等工具的狂热用户。

如今，许多科学研究都涉及一定量的编码，但并非所有科学家都是专业软件工程师，因此像 Claude Code 这样的工具可以极大地提高他们的生产力。

该公司最近赢得了重大科学信任票：本月早些时候，Jumper 宣布他将离开 DeepMind 加盟 Anthropic。

自从由 LLM 提供支持的智能体（包括 Anthropic 的 Opus 模型系列）在 2025 年底变得能够进行有用的独立工作以来，科学家们一直在观察它们能做多少事情。

在 Anthropic 网站上发表的一篇博客文章中，哈佛大学物理学家 Matthew Schwartz 根据他对 Claude Code 和其他 Anthropic 工具的研究估计，该公司的 Opus 4.5 模型执行科学项目的能力与二年级研究生的水平差不多。

据 Kauderer-Abrams 称，Claude Science 无意取代科学家工作流程中的 Claude Code 和 Claude Cowork。

相反，它的设计是基于科学家已经发现的 Anthropic 产品的有用之处。

例如，它不仅可以编写代码，还可以帮助科学家在功能强大的计算机集群上运行代码，这是许多科学家工作所需要的，但可能难以管理。

它优先考虑可重复性，以便科学家可以追溯到任何数据或结果的来源，并检查其准确性和有效性。

尽管克劳德科学原则上可以协助任何领域的科学研究，但它似乎是作为分子和细胞生物学，特别是药物开发的工具而设计和销售的。

它可以与遗传学、化学和蛋白质生物学中使用的各种工具连接，所有这些都可以为寻找新药的研究人员派上用场。

在周二的活动中，领导 Claude Science 开发的 Alexander Tarashansky 演示了该系统如何自主识别苯丙酮尿症（一种罕见的遗传病）的新候选药物。

Anthropic 并没有把所有的工作都交给出席此次活动的制药公司和大学实验室。

在 Claude Science 的支持下，该公司将致力于针对被忽视疾病的候选药物开展自己的研究，以帮助推动科学进步，并更清楚地了解 Claude Science 在现实世界中的运作方式。

在创建通用科学研究工具时，有明显的人道主义原因优先考虑药物开发，人工智能行业领导者经常将治愈疾病视为该技术的主要潜在优势。

但同样值得注意的是，制药公司比学术研究人员拥有更雄厚的财力。

Anthropic 表示，它将迎来第一个盈利季度，如果与制药公司签订重大新合同，他们可以帮助确保公司在代币最大化热潮消退时保持盈利——随着今年晚些时候 IPO 的临近，这一点变得更加重要。
