 Buzz 被定位为 Slack 和 GitHub 的挑战者，是一个适用于工作场所的群聊平台，可将人类及其人工智能代理置于同一对话中。

Dorsey 在 X 上写道，Buzz 是“与模型无关、去中心化、自主主权和开源的”。

这个产品似乎不仅仅是多尔西的一个热情项目。

根据其网站，Buzz 是由 Dorsey 的公司 Block 打造的，该公司还运营 Square、Cash App、Afterpay 和 Tidal 等产品。

随着初创公司越来越依赖人工智能代理来完成工作，员工在不同平台上协作完成各种任务可能具有挑战性。

 Buzz 的实用性在于它将多个不同的工作流程合并到一个工作区中。

它看起来很像 Slack，但具有原生 AI 代理，并且能够从同一窗口管理 GitHub 项目。

由于该平台是开源的，开发人员可以让自己的 Buzz 实例更加适合其特定团队的需求和工作流程。

如果团队需要新功能，他们可以自行构建和部署它，因为他们可以完全访问源代码。
