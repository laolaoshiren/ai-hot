如今每个人都在使用人工智能代理编写代码。

但当代理需要部署某些东西（并且需要注册和创建帐户）时，它就会直接撞向为人类建造的墙壁：基于浏览器的 OAuth 流程、用于点击的仪表板、用于复制粘贴的 API 令牌、需要满足的多因素身份验证提示。

对于坐在开发人员旁边的交互式副驾驶来说，这很烦人。

对于一个后台特工来说，这是一个很难阻止的事情。

今天，我们为代理推出临时 Cloudflare 账户。

代理现在可以立即部署网站、API 和代理，而无需先注册帐户。

现在，任何代理都可以运行 wrangler deploy --temporary 并将 Worker 部署到 Cloudflare。

此临时部署将持续 60 分钟，在此期间您可以认领临时帐户，使其永久属于您自己。

如果不这样做，它就会自行过期。

我们的目标？

让您的代理编码并发货。

为什么无摩擦部署对于人工智能代理很重要
无摩擦临时账户比乍看起来更重要：
- 后台人工智能会话没有人参与，并且正在成为常态。

任何需要浏览器、复制粘贴或“60 秒内单击此处”的身份验证步骤都意味着代理会陷入困境，并可能选择部署到其他地方。

- 试错是特工的超能力。

代理需要一个紧密的写入→部署→验证循环。

他们需要廉价、一次性的部署目标，这样他们就可以调整自己的输出并决定是否正确。

- 代理平台正在构建自己的方式来部署代码以“正常工作”，无需额外的步骤或凭据。

人们开始期望这个过程能够正常工作，而不需要注册他们以前没有使用过或听说过的其他服务。
