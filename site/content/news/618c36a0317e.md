随着人工智能使编码速度显着加快，软件开发中的下一个重大挑战是测试和验证所有代码。

 Blacksmith 已筹集了 4500 万美元的新一轮资金来利用这一转变。

由 Peak XV Partners 牵头的 B 轮融资对 Blacksmith 的估值为 5.5 亿美元，高于不到一年前筹集 1000 万美元 A 轮融资时的 6000 万美元估值。

现有投资者 GV 和 Y Combinator 也参与其中，使该初创公司的总资金达到 5850 万美元。

Blacksmith 成立于 2024 年，帮助公司在软件投入生产之前构建、测试和验证软件。

联合创始人兼首席执行官 Aditya Jayaprakash 在接受独家采访时表示，该初创公司目前为 5,000 多家客户提供服务，包括 Mercury、Supabase、Clerk、Ashby 和 Expensify，而不到一年前，该公司的客户数量为 700 多家。

Cursor、OpenAI 的 Codex 和 Anthropic 的 Claude Code 等 AI 编码工具的兴起使得软件团队生成代码变得更加容易，但 AI 生成的代码的质量并不是给定的。

“验证代码仍然是一个瓶颈，而且是一个更大的瓶颈，因为人们编写的代码甚至更多，”Jayaprakash 说。

Blacksmith 最初是一家持续集成 (CI) 工作负载的云提供商，帮助公司在代码投入生产之前运行验证代码所需的软件构建和测试。

此后，这家初创公司通过 Codesmith 扩大了其平台，Codesmith 是一种人工智能编码代理，可以自动修复失败的代码检查。

Jayaprakash 表示，Blacksmith 在仅 10 名员工的情况下就实现了 1000 万美元的年收入运行，此后其员工人数已增加至约 30 人，收入增长至“数千万美元”。

他拒绝提供具体的更新 ARR 数字，但他确实表示，一些最大的客户现在每年在该平台上的花费超过 100 万美元。

虽然这看起来是坚实而快速的进展，但 Blacksmith 正在一个拥挤的市场中运营。

其主要竞争对手包括 GitHub Actions、Cursor Automations、Codex 和 Claude Code 中内置的验证功能、众多其他初创公司以及 Amazon Web Services、Microsoft Azure 和 Google Cloud 提供的 AI 代码测试服务。

Jayaprakash 表示，他的初创公司正在以测试代码的速度以及可承受性为竞争目标。

展望未来，Jayaprakash 表示 Blacksmith 计划扩展到更广泛的编码工具套件，旨在帮助开发人员更快地编写、验证和合并软件。
