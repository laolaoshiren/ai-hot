ColorOS 正在进一步向 AgentOS 演进。

在 2026 OPPO 开发者大会上，OPPO 正式发布 ColorOS 17，并宣布 OPPO、一加、realme 三大品牌将全面升级 ColorOS，首批机型同步升级 ColorOS 17。

除了新一代流体设计、极光引擎和潮汐引擎，此次大会的另一个重点，是 OPPO 围绕 AIOS 展示了端侧计算、长期记忆、Agent 以及智能体生态方面的最新进展。

据 OPPO 公布的数据，目前 ColorOS 全球活跃用户已经突破 7.7 亿。

此次大会上，OPPO 进一步展示了 On-Device Compute、Persona X 和 Agent Matrix 三大技术方向的最新进展，以及小布 Next、主动服务和多智能体协作等能力。

端侧大模型内存降低 48%，继续强化 AIOS 技术底座
围绕 AIOS，OPPO 此前已经提出新计算、新感知和新生态三大技术方向。

在新计算层面，OPPO 此次公布的 On-Device Compute 端侧大模型采用 Linear Attention 架构，可原生支持 128K 上下文。

根据 OPPO 公布的数据，相比上一代，其内存占用降低 48%，能耗优化 55%。

在新感知层面，Persona X 记忆共生引擎进一步覆盖数据感知、环境感知和行为感知，并引入记录、遗忘与反思等机制，用于支持 AI 在长期使用过程中持续积累和更新对用户的理解。

在新生态层面，Agent Matrix 智能体生态框架也进一步升级。

围绕 Agent，OPPO 展示了包括 Agent 原生架构、事件驱动与多智能体协同，以及 A2A、MCP、Skill 能力调用等在内的技术布局，同时还涉及账号身份、意图共享、支付授权等智能体执行任务过程中需要的基础能力。
