在四月份凭借其首个内部 Muse Spark 模型重新进入人工智能竞赛后，Meta 现在向开发人员敞开了大门，推出了一种新模型，该模型可以通过新的 Meta Model API 插入人工智能编码软件。

Meta 表示其新的人工智能模型已准备好在编码领域展开竞争
Muse Spark 1.1 通过公共 API 预览版向美国开发者开放。

Muse Spark 1.1 通过公共 API 预览版向美国开发者开放。

Meta 表示，Muse Spark 1.1 是第一代的“阶跃变化”，根据开发人员的反馈进行了改进。

该公司表示，它能够进行更高级的编码，包括检测和修复复杂的错误；更好地支持跨一系列应用程序的端到端代理工作流程，包括多代理系统；并具有跨图像、视频和文档的原生多模态感知。

Muse Spark 1.1 是在本周推出的 Muse Image 之后推出的，Muse Image 是一种图像生成模型，因其能够将其他用户的 Instagram 内容合并到其世代中而受到争议。

这是 Meta 竞赛的一部分，目的是证明其花费数十亿美元来追赶人工智能竞争并试图与 OpenAI、谷歌和 Anthropic 等公司平起平坐，尤其是在去年进行了大量高调招聘和公司重组之后。

新的 1.1 模型现已在 Thinking 模式下通过 Meta AI 应用程序和 Meta AI 网站提供。

它还可以通过新的元模型 API 进行访问，该 API 从今天开始向美国开发者提供公共预览版。

 Meta 为每个新的 Meta Model API 帐户提供价值 20 美元的免费积分。

 Muse Spark 最初只能直接通过 Meta AI 获得，后来最终为 Instagram 和 WhatsApp 内的聊天机器人以及最新的 Meta 智能眼镜提供支持。
