更进一步，这家初创公司声称其基础设施可以自动化建立和运营企业的大部分工作——当然，前提是你提供人工智能代理和所需的代币预算。

它将支付、电子邮件帐户、电话号码、云基础设施、存储和公司合并的流程打包在一个 API 后面。

Naïve 提供了一个提示，开发人员可以向 Cursor、Claude Code 或 Codex 等工具提供提示，这些工具可以连接到公司的 API 来配置基础设施以建立业务。

它允许代理精心策划美国有限责任公司的组建，提供州、行业代码、业务描述和拟议名称等详细信息，但用户仍需要参与完成 KYC/KYB 流程并支付任何所需的付款。

其余的设置可以由 AI 代理完成，包括设置电子邮件收件箱、虚拟卡、电话号码、数据库、计算资源以及与 Stripe 和 QuickBooks 等服务的连接。

治理层承诺帮助用户设定预算，限制其代理的能力，并在执行敏感操作之前需要人工批准。

该公司还为企业提供模板，例如人工智能搜索引擎优化、全栈SaaS应用程序、招聘、会计、客户支持，甚至还有一个移动模拟器，代理商可以使用该模拟器在模拟设备上操作智能手机应用程序。
