X 使 Claude、Cursor、Grok Build 等 AI 助手和其他 MCP 兼容应用程序可以更轻松地通过新的托管 MCP 服务器直接连接到平台。

托管模型上下文协议 (MCP) 服务器
允许 AI 工具使用用户自己的帐户权限与 X API 进行通信。

MCP，就上下文而言，是一个开放标准，定义了人工智能模型连接到外部工具和服务的通用方式。

以前，如果开发人员想要像 Claude 或 Cursor 这样的 AI 助手访问 X，他们必须构建自己的 MCP 服务器、托管它、连接到 X API 并处理身份验证。

现在，X 托管 MCP，用户使用自己的 X 帐户的权限进行身份验证。

这使得开发人员可以节省花在集成工作上的时间，从而专注于他们实际构建的内容。

开发人员长期以来一直能够使用该平台的 API 搜索 X、阅读帖子、查找用户、分析对话和趋势以及执行更多操作。

托管 MCP 并未在这方面添加新功能；它只是让他们更容易接触人工智能应用程序。

通过这样做，X 可以将自己定位为一个充满实时数据以供检索和分析的信息网络，而不仅仅是一个社交场所。
