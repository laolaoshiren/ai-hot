OpenAI 周二宣布它已经解决了数学界的传奇千禧奖问题之一，这本应该是一个胜利的时刻。

结果既是不可否认的成就，又惊人地展示了人工智能正在如何迅速地改变数学。

但在正式宣布之前，这一突破就因促使 OpenAI 解决这个问题的不寻常情况而变得复杂：在听说其他研究人员取得进展后，它似乎投入了大量资源，在最后一刻努力抢先一步。

随之而来的争议出现了有关独家报道、间谍活动和公然违反长期存在的学术规范的指控，研究人员担心这些行为可能会对该领域产生寒蝉效应。

正如伦敦玛丽女王大学数学教授 Abhishek Saha 所解释的那样，OpenAI 从事的是“数学家通常不会做的事情”。

OpenAI 在周二发布的一篇博文中表示，其未发布的模型仅用了 88 小时就找到了纳维-斯托克斯问题的解决方案，这是一个有关流体运动的棘手难题。

由于解决这个问题的人可以获得 100 万美元的悬赏，这个问题是数学研究最深入的问题之一，但它仍然困扰了人类研究人员近 90 年。

 OpenAI 表示，其模型通过将由其内部模型驱动的约 10,000 个人工智能代理集中到任务上来解决这个问题，并称赞这一成就是一个“里程碑”。

“如果你不想让我友善，那我就不必友善。

”
但宣布这一消息的时机却引起了人们的关注。

就在一天前，纽约大学数学教授 Tristan Buckmaster 与 OpenAI 的主要竞争对手 Anthropic 的研究员 Levent Alpöge 发表了有关相关问题的研究结果（尽管 Alpöge 在这里并不是代表他的雇主工作）。

 Buckmaster 表示，在得知 OpenAI 公司已经了解他们的进展后，他联系了 OpenAI，询问该公司何时开始解决该问题以及其模型接受了哪些数据训练。

他说，谈话很快就变得很糟糕，一位 OpenAI 研究人员问他：“你为什么要毁掉你的职业生涯？

” OpenAI 敦促巴克马斯特发表该作品，并将其归功于 OpenAI 的内部模型，并放弃 Alpöge 作为合著者。

巴克马斯特表示，他询问 OpenAI 是否访问了他在解决问题时使用的 Codex 会议，但 OpenAI 在回应中变得越来越回避，甚至充满敌意。

在随后的声明中，包括宣布结果的博文中，OpenAI 断然否认使用任何特定的用户数据。

该公司表示：“在他们公开发布之前，我们（研究人员和代理人）没有通过任何方式看到他们的任何工作，特别是，没有为了解决这个问题而访问任何特定的用户数据。
