TornadoVM
TornadoVM 6.0.0 发布，带来 Bug 修复、文档改进、依赖项升级以及以下新功能：在后端和库任务中，完全用更现代的“外部函数与内存 API ”取代了 Java 本机接口（JNI）； 移除了实验性的 JVM 编译器接口（JVMCI），转而“通过反射 + ASM + Unsafe 层获取所有编译器元数据，所有受支持的 JDK（21、25、26、27）都会将此作为唯一的统一路径”；扩展了 CUDA 后端。
