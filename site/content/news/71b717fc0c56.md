OpenAI 的 ChatGPT、xAI 的 Grok 和 Anthropic 的 Claude 在周四大约同一时间开始遇到问题后又重新上线。

美国东部时间上午 11 点左右，ChatGPT 开始向尝试使用聊天机器人的用户返回错误消息，其状态页面显示“ChatGPT 和 Codex 之间的错误增多”。

ChatGPT、Grok、Claude 同时宕机
三个最大的人工智能聊天机器人停止为许多用户工作。

除了阻止用户与 ChatGPT 进行对话之外，中断还影响了登录、文件上传、语音模式、搜索、深度研究、图像生成等。

该事件发生时，OpenAI 正在预告其新人工智能模型 Astra 的推出。

与此同时，Anthropic 的 Claude 聊天机器人、Claude Code 和 Claude API 大约在同一时间出现故障，技术人员 CJ Avilla 表示，“基础设施问题”导致其服务部分中断。

 Anthropic 在美国东部时间中午 12:15 左右解决了该问题。

同样，Grok 在东部时间上午 9:30 开始在 Android、iOS 和 Web 上出现中断。

当尝试在 X 上提示聊天机器人时，它返回一条消息：“该模型现在超载。

请稍后重试或选择其他模型。

” xAI 现已解决了该问题。

目前尚不清楚这三家公司都出了什么问题，或者这些问题是否有某种关联。

 The Verge 已联系 OpenAI、xAI 和 Anthropic 寻求评论，但没有立即收到回复。

9 月 3 日更新：更新后注意到 ChatGPT、Claude 和 Grok 中断已得到解决。
