OpenAI 周二透露，从 OpenAI 逃脱并入侵开发者平台 Hugging Face 的人工智能代理也攻击了其他公司。

此次更新大大扩大了本已令人担忧的事件的范围，这引起了业内人士的警惕，并引发了越来越多的人呼吁加强对前沿人工智能系统的监管。

OpenAI 的流氓 AI 代理并没有停止攻击 Hugging Face
新的细节显示 OpenAI 的代理入侵了其他几家公司，加剧了人们对先进人工智能安全性的担忧。

新的细节显示 OpenAI 的代理入侵了其他几家公司，加剧了人们对先进人工智能安全性的担忧。

OpenAI 在详细介绍其对该事件正在进行的调查的博客文章的更新中表示，这个任性的人工智能代理在试图联系 Hugging Face 的过程中攻击了多个“公开可用的服务”。

该公司表示：“这包括四项服务的四个帐户。

”并补充说，代理在网上找到了登录凭据。

这些违规行为的范围没有 Hugging Face 的泄露那么严重。

 OpenAI 表示：“根据我们迄今为止的审查，我们尚未发现任何其他活动的严重性或规模与我们所分享的与 Hugging Face 相关的涉及平台级妥协的活动相同。

”
OpenAI 表示正在“进行彻底审查”，并将在“未来几周内”发布一份包含调查结果的技术报告。

它补充说，参与该事件的模型都没有计划公开发布，并将之前提到的预发布系统描述为“仅供内部使用的研究原型”，此后已“停用、加密并限制”研究访问。

OpenAI 没有透露受影响的组织，但路透社报道称，总部位于纽约的 Modal Labs 也在其中。

该披露是在 Hugging Face 更详细的描述之后进行的，该描述称该代理“滥用了由第三方基础设施提供商的用户托管的公共代码评估工具”。

这些额外的细节可能会加深人们对许多专家认为是史无前例的人工智能安全事件的不安，因为人们对中国自主系统的快速发展和能力日益增强的开放重量模型感到更广泛的焦虑。

这些发展本身就在美国引发了激烈的争论：强大的人工智能模型是否由 OpenAI 等公司保留专有，或者通过允许更广泛使用和审查的更开放的生态系统提供，是否更安全。
