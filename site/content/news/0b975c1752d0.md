周二，Anthropic 发布了 Fable 和 Mythos 5.1，这是该公司最先进的人工智能模型的孪生版本。

除了性能升级之外，新的《Fable》版本还包括旨在降低代币成本和模型保护措施的误报限制的更改。

与之前的 Mythos 模型一样，Mythos 5.1 仅适用于从事网络安全或生命科学研究的注册 Anthropic 合作伙伴。

 《神鬼寓言 5.1》是无限制版本，从今天开始可在云平台或通过 Anthropic API 获取。

最重要的变化之一是 Anthropic 的
之前报道过
拥抱零数据保留，允许客户在自己的基础设施上运行人类模型而不会出现数据外流。

由于安全问题，《神鬼寓言》之前无法使用一项高隐私服务（称为
企业边境保障
）将于六月向用户推出。

值得注意的是，系统仍将监控代理或人类用户的滥用情况，但客户将控制监控的方式。

公告

声明中写道：“未经明确许可，Anthropic 从未对企业数据进行过培训，也永远不会。
