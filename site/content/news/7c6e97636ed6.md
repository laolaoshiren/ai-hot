这一安排与微软在 2018 年出售的 GitHub 收购故事的简洁版本背道而驰：购买开发者平台，将其基础设施转向 Azure，并使微软的云成为世界软件工作的默认基础。

相反，GitHub 的负载曲线变化速度快于迁移计划。

 Business Insider 报道称，微软原计划到 2027 年将 GitHub 完全迁移到 Azure，但现在正在从 AWS 增加额外容量，同时该平台还要应对中断和更高的使用率。

微软确认了更广泛的多云转变，但没有透露 AWS 的名称。

一位发言人告诉 Business Insider，自 2025 年底以来“代理开发的令人难以置信的激增”已经考验了 GitHub 的基础设施限制，并表示微软正在加速 Azure 迁移，同时探索弹性和规模的多云战略。

亚马逊告诉媒体，它不会对个人客户发表评论。
