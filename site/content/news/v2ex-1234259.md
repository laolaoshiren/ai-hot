总命中率 = (System Cache Hit + History Cache Hit) / Total
= [ C × hit_rate_system + ΣΔ(k) × hit_rate_history ] / [ C + ΣΔ(k) + d ]
代入场景数据：
系统提示（含工具）：1500–3000 tokens
历史对话（ 10 轮）：4000–8000 tokens
当前输入：20–100 tokens
则：
命中率 = (3000 + 8000) / (3000 + 8000 + 50) ≈ 99.5%
