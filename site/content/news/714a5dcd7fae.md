Claude Science 是 Anthropic 的最新旗舰产品
在昨天为制药公司高管、生物技术创始人和研究人员举办的活动中，Anthropic 宣布推出 Claude Science，这是一款旨在支持科学研究的重要新产品，就像 Claude Code 支持软件工程一样。

与 Claude Code 一样，Claude Science 可以利用计算生物学和药物开发工具，根据简洁、高级的指令自主开展有意义的工作。

此次发布标志着 Anthropic 正在加大人工智能在科学领域的投入，该公司还将将该产品用于自己的治疗罕见、被忽视疾病的药物研究中。

为什么加州的碳肥数学不成立
加州的气候政策有些糟糕。

多年前，该州建立了一项制度，向养牛户支付费用，将牛粪排放的甲烷转化为天然气。

它变得非常受欢迎，因为补贴非常有利可图。

但研究表明，该计划暴露了碳抵消和交易计划的缺点。

立法者没有强迫企业直接减少污染或将其作为经营成本来支付，而是选择了在各方和地区之间交换气候责任的激励措施。

该系统最终可能会导致更多的变暖。
