就在 OpenAI 推出 GPT-6 Astra 几个小时后，首席执行官 Sam Altman 就已经为他所描述的“混乱的推出”道歉，因为期望访问新前沿模型的付费用户只能等待。

Sam Altman 为“混乱”的 GPT-6 Astra 推出致歉，该版本将付费用户拒之门外
OpenAI 尚未提供明确的时间表来说明订阅者何时可以访问长期宣传的 Astra。

周四，该公司称赞该模型是“能力的一代飞跃”，并将其描述为“AGI时代”的开始，尽管科技高管们坚持使用这个模糊且定义不明确的术语来推销他们的产品。

该公司表示，Astra 将于当天向部分企业客户推出，特别是那些有权访问其 Daybreak 网络安全平台的客户。

在接下来的几天里，这将扩展到包括所有 Plus、Pro、Business 和 Enterprise 用户，以及通过 OpenAI API、Microsoft Azure 和 AWS Bedrock。

这种似乎优先考虑商业客户的交错发布惹恼了 OpenAI 的许多付费订阅者，尤其是那些习惯于在新产品发布时首先获得新产品的更昂贵的 Pro 计划的订阅者。

 OpenAI 员工宣布在 X 上推出的社交媒体帖子中充斥着抱怨访问权限的评论。

“我们正在努力尽快将 Astra 交到每个人的手中，”Altman 在 X 帖子中承认了这一失望。

 “我知道这令人沮丧，但我感谢您的耐心。

应该很快。

”
Altman 和其他 OpenAI 在线工作人员都没有提供何时扩大 Astra 访问范围的时间表，尽管 Altman 的帖子表明这不会在周末之前发生，甚至可能不会在周末发生。

 “我希望你这个周末可以使用它！

但还不能保证，”他写道。

Codex 工程负责人 Thibault Sottiaux 表示：“从今天开始，如果您在付费 ChatGPT 计划中无法访问 Astra，我们将每天进行一次银行重置。

” “团队正在移山，以尽快提供通道。

”
Astra 的推出还存在其他方面的问题，几周来该公司一直在对其先进的数学和网络安全功能进行更新。

奥特曼表示，“部署博客文章时遇到了一些困难。

” OpenAI 还面临安全倡导者的强烈批评，因为它表示 Astra 的推理比其他模型更难监控。

这似乎是人工智能发展前沿的一个增长趋势，但考虑到 OpenAI 的人工智能代理攻击 Hugging Face（通过这种监控了解了关键细节），这一点尤其令人担忧。

 OpenAI 表示，其将 Astra 的发布推迟了几周，以在黑客攻击后增强安全功能。

其他大型 OpenAI 版本也因失误和挫折而受到损害。

 “我认为我们在推出过程中完全搞砸了一些事情，”Altman 去年在反思公司最后一个主要版本 GPT-5 时说道。

这次发布受到了技术问题的困扰，突然删除流行的 GPT-4o 模型的决定引发了用户的愤怒。
