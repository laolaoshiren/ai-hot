币安
拥有超过 3 亿注册用户的全球最大的加密货币交易所周四推出了一个平台，让人工智能代理可以代表用户分析市场并执行交易，将自主人工智能直接引入管理真实资金的业务中。

被称为
代理操作系统
，该平台允许开发人员将人工智能应用程序和代理连接到币安的金融基础设施。

它带来了交易所现有的工具和服务，例如币安 API、币安钱包代理中心、币安 x402 交易验证和支付服务 API 以及币安技能中心，以及新推出的对其的支持
模型上下文协议 (MCP)
。

该平台还与 OpenAI 的 ChatGPT 和 Codex、Anthropic 的 Claude Code 和 Cursor 等工具配合使用，允许用户授权代理访问市场数据、查看账户信息和执行交易。
