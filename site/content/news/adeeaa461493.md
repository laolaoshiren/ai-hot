据《纽约时报》和《连线》早些时候报道，OpenAI 表示，它找到了一个大约 90 年来一直悬而未决的重大数学问题的解决方案。

在周二的一篇博客文章中，OpenAI 宣布它发现了一种解决纳维-斯托克斯问题（与液体和气体流动有关）的解决方案，该问题使用比新发布的 GPT-6 Astra 更强大的内部 AI 模型以及 10,000 个并发代理。

纳维-斯托克斯问题是七个千年奖问题之一，解决每个问题都会获得 100 万美元的奖励。

戏剧围绕 OpenAI 的传奇数学里程碑展开
OpenAI 在解决 90 年老问题上的突破受到了前一天解决相关问题的研究人员的挑战。

OpenAI 表示，它于 8 月 28 日开始训练内部人工智能模型，该模型“在我们的基准测试中表现出了前所未有的性能，包括数学。

”这个解决方案对于数学界来说是一个重大突破，但也并非没有争议。

就在 OpenAI 宣布这一消息的前一天，纽约大学数学教授 Tristan Buckmaster 与 Anthropic 研究员 Levent Alpöge 合作发表了有关相关问题的研究结果。

巴克马斯特在宣布这些发现时声称，他在得知 OpenAI 听说了他们的进展后联系了该公司。

然而，Buckmaster 发现 OpenAI 已经使用他和 Alpöge 一直在与 OpenAI 的 Codex 和 Anthropic 的 Claude 合作的路线生成了 Navier-Stokes 方程的证明。

Buckmaster 在声明中对 OpenAI 是否访问了他们的 Codex 数据以更接近 Navier-Stokes 解决方案表示担忧。

巴克马斯特写道：“我询问该模型是否接受过 Codex 会议的培训或访问过我们的会议，我们已将整个项目的所有草稿放入其中。

” “我被告知该模型没有查找用户数据。

我再次询问有关训练的问题，但没有得到答案。

”
OpenAI 现在正试图通过周二的声明来消除这些怀疑，称“为了解决这个问题，没有访问任何特定的用户数据。

”它补充说，“虽然可能性不大，但我们不能排除从他们使用我们产品时获得的去识别化数据有助于改进我们的模型。

”当联系到 OpenAI 寻求评论时，OpenAI 向 The Verge 指出了其关于 X 的声明，这与其博客文章相呼应。

OpenAI 的技术人员 Sebastien Bubeck 也同样表示：“我们没有看到他们（Buckmaster 和 Alpöge）的任何工作，直到他们昨晚公开发布。

事后看来，我们的证明存在很大差异，甚至证明的精确结果也不同。

”
与此同时，Buckmaster 在 Mastodon 上的一篇帖子中对此做出了回应，声称 OpenAI “公开承认他们使用了我们发现结果后一段时间的训练数据。

”
OpenAI 表示不打算获得 100 万美元的奖金。
