如果您曾经想与 OpenAI 分享所有数字对话，我们有个好消息给您：AI 实验室刚刚推出了适用于 ChatGPT 的 Apple Messages 插件，允许感兴趣的用户将他们的 Messages 收件箱与聊天机器人连接起来。

OpenAI 认为，这样做的好处有很多。

用户可以使用该插件直接从 ChatGPT 排序、分析或编辑消息。

该插件还可以与 Codex 和 ChatGPT Work 配合使用，因此用户可以专业地使用它，而不仅仅是个人。

简短的广告
新插件的广告显示，用户要求聊天机器人根据前一天收到的消息向其联系人建议后续消息。

您还可以要求 ChatGPT 为您删除消息、代表您起草和发送消息，或者搜索隐藏在消息历史记录深处的信息。

与大多数与人工智能相关的事物一样，这一新功能引发了一些隐私问题。
