我也算是从去年底就开始使用 AI 编程，Cursor 这类，再到 CLI 类 Codex 、claudecode 、gemini ，再到 CodeX 页面类型的，基本都玩边了，最终发现还是 ClaudeCode 适合我，因为可以使用各种不同厂商的 token ，
早期 火山引擎 codingplan 200/月 就可以解决所有问题，甚至用都用不完。

到后面，一家根本不够用，自己用服务器搭了 new-api ，
接上 朋友那买的，咸鱼买的，淘宝买的各类中转站
阿里 tokenplan(codingplan 等发现这玩意儿很值后，就根本抢不到了）
智普 codingplan ，火山的 codingplan Pro 依旧续费着、Deepseek
上个月 token 单月统计消耗量 40 亿出头，（这里面自己开发，一些 agent 日常消耗，主要开发多）
早期都是挑最贵最牛的模型，现在要降低两个档位只为了可以处理更多次任务，已经给我搞出 token 焦虑了。

几乎每个月成本在 600 左右
也有朋友推荐我 codex ，那这样我一些 agent 就无法使用了，一个核心功能 claude -p ，而且很大一部分 token 都是中转站承担起来的，我并不信任他们的安全或说 token 质量，但是中转站确实承担了非常大的开发能力 或说是 agent 日常消耗。
