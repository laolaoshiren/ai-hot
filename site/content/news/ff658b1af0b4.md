OpenAI 终于发布了一些硬件。

不，这不是该公司与前苹果设计师 Jony Ive 共同开发的神秘人工智能设备，该项目已经陷入了一场混乱的诉讼之中。

相反，它是一款设计用于与其编码平台 Codex 一起使用的产品。

与 Work Louder 的合作与 OpenAI 的主要硬件项目是分开的，据传是某种智能扬声器。

该设备是一个名为 Codex Micro 的方形按钮块，是人工智能公司和键盘制造商 Work Louder 之间的合作产品。

 OpenAI 表示，这是一项有限的合作，将为用户提供更多监控和管理代理的方式。

该键盘与 Work Louder 的 Creator Micro 2 非常相似，营销图片显示了由 13 个机械开关组成的相同阵列，以及操纵杆、拨盘和触摸传感器。

该设备看起来也与 Figma 于 2023 年生产的独立垫 Work Louder 非常相似。

OpenAI 表示 Codex Micro 售价为 230 美元，可在 Supply Co 上购买，售完即止。

它没有具体说明有多少单位可以作为合作伙伴关系的一部分。

在解释该设备的视频中，Work Louder 联合创始人 Mike Di Genova 表示，Micro 有六个磨砂按键，可以提供“Codex 线程的实时视图”，使用不同的颜色来指示任务的状态，例如任务是否已完成、需要反馈、正在运行或遇到错误。

还有一些命令键可以分配给常见操作，例如一键通、接受或拒绝更改以及发送，并且该设备还附带 32 个 Codex 图标的附加键帽。

操纵杆和转盘还可以分别用于启动常见工作流程和调整推理级别，OpenAI 表示所有控件都可以通过 ChatGPT 桌面应用程序进行配置。

该设备独立于 OpenAI 与 Ive 共同开发的主要硬件项目。

有关该设备的详细信息很少，但有报道称它将是某种智能扬声器，可以让你与 ChatGPT 交谈。

有传言称它将于明年某个时候推出。

本周，苹果提起诉讼，指控 OpenAI 窃取硬件机密，该产品再次受到审查，苹果称这些指控毫无根据。
