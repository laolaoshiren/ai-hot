两个月前在这里发过 mdview ，今天来交个底，顺便有件拿不准的事想听听大家的意见。

补一段背景：mdview 是个 Markdown 阅读器（也有人叫查看器），内置两种编辑功能，就地编辑和分屏编辑。

Windows / macOS / Android 都有，安装包 2MB 。

双击 .md 文件直接看，像浏览网页一样，Esc 关掉走人。

做它是因为每次想看一眼 README 或者 AI 导出来的文档，不想开一个笨重的软件来查看，看完之后随手关掉，需要修改也没问题。

社区版阅读功能不阉割、免费用； Pro 是编辑、Mermaid 图表、数学公式、导出增强，¥5 永久，前 100 次免费试用。

两个月的账：
装机 12000 多台，匀速涨上来的，中间没有爆过量
版本发了 140 多个（原生 PDF 导出、单文件 HTML 导出、F2 就地编辑都是这两个月里做的）
收入 1000 出头，付费用户两百多个，折下来转化率 1.6%
成本那边没什么可哭的：服务器加域名一年几百块，早被收入覆盖了。

真正的成本是时间——这两个月我基本全职在做，平均一两天发一个版。

拿收入除以投入的工时，不如去便利店打工。

所谓难以为继，不是活不下去，是投入产出撑不住「全职做」这个决定：要么想办法让收入上一个量级，要么重新找个工作、把它降级成业余项目。

我选前者，第一个动作是涨价。

为什么觉得有涨的空间：¥5 是两个月前上付费时随手定的，图个「交个朋友」。

现在回头看用户反馈，夸的是快、干净、阅读体验好，没有一条夸便宜。

个人开发者，舍不得钱，渠道上没投过一分钱广告，主要靠搜索和口碑，大部分是被搜索引擎推荐过来的。
