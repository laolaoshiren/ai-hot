Meta 在人工智能利用领域被认为有点落后，但它正在大步追赶。

本周，该公司发布了一款新的终端编码代理，旨在帮助程序员在大型软件代码库中完成复杂任务。

Meta 首席执行官马克·扎克伯格 (Mark Zuckerberg) 在周三的社交媒体帖子中表示，目前提供测试版的 Muse Code 可以完成“跨大型存储库的完整软件工程任务”。

他补充说，这些任务包括“计划变更、编写代码、验证结果”。

代码可以通过单个命令安装，由 Meta 之前发布的编码模型 Muse Spark 提供支持。

它通过启动自己的代理来处理大型项目，然后这些代理同时工作。

扎克伯格解释说：“当一项工作足够大时，它就会分散到在孤立的工作树中并行工作的独立子代理上。

” “你的工作副本永远不会被触及。

在测试中，我们让它同时为游戏构建六个功能，不会发生冲突。

”
此举试图让 Meta 与 OpenAI 及其编码代理 Codex 等人工智能实验室同行以及与 Claude Code 的 Anthropic 相比更具竞争力，也更经济。

Meta 超级智能实验室领导者 Alexandr Wang 告诉《华尔街日报》：“我们认为，对于很多工作流程和很多用例来说，这可能是一个非常好的选择，尤其是从成本角度来看。

”
Meta 一直试图通过投入资金进行开发来扩大其人工智能业务。

 6月，它超越了利用人工智能支持广告业务的核心重点，并通过旨在客户服务和支持的代理进入企业人工智能市场。
