之后，我想让文本可复制粘贴。

因此，我将图像放入一个带有文本叠加层的 SVG 文件中：
字体（Barlow Condensed – Italic Condensed）和行高大致符合我的笔迹尺寸。

对于间距，我的想法是添加间距字符，这些字符将在网页上触发的复制粘贴事件期间在 Javascript 中删除。

我使用`（反引号）字符来表示将被完全删除的狭窄空格，以及单词之间的多个空格，我计划将它们折叠成仅 1 个空格。

超链接是使用 Inkscape 的创建锚点功能创建的。

导出SVG文件后，需要进行一些后期处理：
- 使用 <style> 嵌入字体
- 将 ` 字符替换为六个空格字符，以便选择时不会显示反引号
- 用完整的 URL 替换链接的本地图像文件路径
最后，SVG 作为 <svg> 元素完全添加到 HTML 文件中。

如果我将其嵌入为 <object>，则无法触发复制 Javascript 事件。
