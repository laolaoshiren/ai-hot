OpenJDK
JEP 541，Deprecate the macOS/x64 Port for Removal，已经从 Candidate 提升为 JDK 28 的 Proposed to Target 状态。

该 JEP 建议弃用 macOS/x64 端口，因为苹果公司不再支持该架构。

与 JEP 449，Deprecate the Windows 32-bit x86 Port for Removal类似，目标是在未来版本中移除该端口以节省维护成本。

JEP 540，Simple JSON API (Incubator)，也已经从 Candidate 提升为 JDK 28 的 Proposed to Target 状态。

该 JEP 定义了一个简单的标准 API，用于解析与生成 JSON 文档，无需外部库。

此功能实现了 RFC 8259，The JavaScript Object Notation (JSON) Data Interchange Format，并取代了已关闭并撤回的 JEP 198，Light-Weight JSON API。
