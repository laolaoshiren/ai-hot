办公智能体正在成为热门赛道。

写文档、做表格、订会议，各家都在往办公软件里加入更聪明的 AI 助手。

但实际工作很少一次生成就结束。

搜集资料、撰写修改、交接文件、同步进度……任务越复杂，需要协调的角色和环节就越多。

当 AI 开始接手这些工作，一个新的问题也随之出现：
多 Agent 和人能不能像团队一样分工、接棒和协作？

openJiuwen 最近给出了一种探索——WorkSwarm 蜂群办公智能体，将多智能体协作进一步带入个人办公场景。

openJiuwen 由华为 2012 实验室、华为云、终端、计算联合构建。

上周，openJiuwen 宣布将旗下蜂群智能体升级为 WorkSwarm，率先上架鸿蒙 PC 应用市场，并支持 Windows、Mac 等平台。

想看看它能怎么用，可以从几个有趣的案例开始：让七个 Agent 分别负责作词、作曲、编曲和演唱，共同完成一首歌；也可以让两名 AI 写作者和一名真人共享同一份 Word 文档，接力续写《岳阳楼记》。

这些案例背后，是同一套 Agent 协作逻辑。

WorkSwarm 根据目标召集不同能力的 Agent，分配任务，让成员共享项目背景和最新成果，并接着上一步继续工作。

用户可以随时查看进度、调整要求，也可以加入团队，亲自完成其中一环。

针对不同复杂度的任务，WorkSwarm 提供单 Agent 和集群两种模式。

查询、文字修改等轻量工作可以交给单个 Agent；涉及多个角色、多轮交付的复杂任务，则由多个 Agent 协同完成。

成员讨论、任务状态、执行记录和项目文件都集中在同一个工作台中。

一个 AI 助手，也由此变成一支与你共同工作的 Agent 团队。

一个人来回倒腾的活，交给一支会接棒的团队
