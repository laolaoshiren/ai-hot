Cloudflare 最近推出了 Kitesurf
，一款专为自动化工作负载构建的轻量级浏览器。

Kitesurf 在 Cloudflare Workers 上隔离的 WebAssembly/Rust 环境中运行浏览器组件，并支持 Chrome DevTools 协议，允许 Playwright 和 Puppeteer 等工具以低于完整 Chromium 浏览器的资源开销来驱动它。

Kitesurf 专为截图和 HTML 提取等任务而设计，在长生命周期的 Dynamic Worker 中运行每个页面或跨进程 iframe（OOPIF），每个实例都拥有独立的 JavaScript 环境与 DOM，实现环境隔离。

Kitesurf 使用了基于 Rust 的
Blitz
渲染引擎和 Firefox 的
Stylo
CSS 解析器。

Kitesurf 目前还不能替代 Chromium，它尚不支持视频、WebGL、真实环境下基于 TLS 的机器人验证，也不支持长时效已认证会话。
