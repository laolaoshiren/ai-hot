从人们记事起，GitHub 就一直是大多数开发人员首选的事实上的代码托管平台。

然而，最近一段时间，该平台却陷入了困境。

广泛报道
中断和性能下降，当它丢球时，光标正在等待捡起它。

正式成为 SpaceX 的一部分
本周推出了 Origin——一个新的代码托管平台，旨在完成开发人员通常使用 GitHub 进行的所有操作：协作处理代码库、浏览和编辑它们、处理拉取请求（其他人要求添加到主代码库中所做的编辑），并将它们存储在存储库中。

对于 Cursor 来说，这似乎是自然而然的下一步，到目前为止，其主要关注点一直是通过以下方式销售自动化 Web 开发服务：
它的人工智能代码编辑器
。

 Cursor 还表示，“原生代理”功能很快就会在 Origin 上推出，不过尚未透露很多细节。

该公司还表示，正在构建更广泛的“应用程序生态系统”，以支持 Origin 内更广泛的编码工作。

有趣的是，使用 Origin 并不要求用户停止使用 GitHub。

事实上，Origin 旨在允许开发人员与 GitHub 一起工作，并以可互操作的方式在两者之间来回传递代码。
