DeepSeek 于上周四发布了 DeepSeek Harness 开发者预览版，并开放了源代码。

InfoQ 对此做了专题报道：DeepSeek 把 Harness 开源了：模型、工具、Agent Loop 全是插件。

与只提供对话界面的 AI 编程工具不同，DeepSeek Harness 更关注 Agent 的完整运行环境：模型从哪里接入，Agent 以什么方式工作，终端、文件系统、网页搜索、计划和子 Agent 等能力又该如何组合。

它的核心设计理念是“一切皆插件”。

模型、工具、会话、权限乃至 Agent 循环，都可以通过插件进行组装和替换。

这种设计为开发者提供了很高的灵活性，同时也带来了一些新的学习门槛：四种不同的 Agent 预设分别适合什么类型的任务？

标准模式和 PTC 模式的区别在哪里？

那么多插件究竟怎么选？

它们分别解决什么问题？

第一次使用时应该从哪里开始？

一套可以边做边学的极简教程
针对这些问题，极客时间教研组整理了一套开源的《DeepSeek Harness 极简入门教程》（点击即可免费领取）。

这套教程没有按照功能列表逐项解释配置，而是设计了一个贯穿始终的小项目 Task Lens，让读者在完成真实任务的过程中理解产品。

教程从一个空目录开始，带着读者启动 DeepSeek Harness，让 Agent 创建项目、读取文件、运行测试。

后续再围绕同一个项目切换模型 Provider、比较不同 Agent 预设的区别、并带着大家配置并使用各种常用插件，并最终完成一次包含代码、测试、示例数据和文档的功能升级。

整套教程由 7 篇短文组成，按照主线操作，一到两个小时即可完成。

它不要求读者提前通读源码或架构文档，也不会把大量配置字段堆在一起，更适合希望先建立整体认识、再继续深入研究的开发者。
