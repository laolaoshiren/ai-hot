Slack 正在引入专用通道，团队可以在其中与 AI 代理一起进行振动编码，而不是在不同的工具和对话之间跳转。

 Slack Code 的发布包括带有专用用户选项卡的开放式、特定于项目的代码通道，以及在项目发布之前比较编码更改和预览 HTML 输出的功能。

Slack 正在推出协作振动编码频道
Slack Code 为团队与 AI 代理协作提供了专用的开放空间。

Slack 在其新闻稿中表示：“使用 Slack Code，当你有想法或需要构建新功能、更新网页或修复错误时，你只需标记一个编码代理，例如 Anthropic 的 Claude 或 Cognition 的 Devin，然后该代理就会启动一个代码通道来处理该任务。

” “在那里，每个人都可以完全了解对话，可以审核代码差异，实时预览代理的输出，提供反馈，并在发布之前批准工作。

”
编码通道设计为在完成其专用任务后自动存档，并提供审计日志以进行记录保存。

 Slack 将此功能定位为一种与 AI 代理“像队友一样”协作的简单方法——SpaceXAI 也试图通过其新的 Grok Bot 代理向人们推销这种心态。

从今天开始，任何 Slack 计划都可以使用 Slack Code。

它将与 Slack 市场上提供的人工智能代理配合使用，Slack 表示，其创始合作伙伴（包括 Claude Code、Devin、Vercel Agent 和 GitHub Copilot）的代理将与代码通道“无缝集成”。
