OpenAI 最新的数学里程碑很快就陷入了争议。

今天，该公司宣布其代理人已经解决了千年奖问题之一，这是数学中一些最重要的开放问题。

在正常情况下，该解决方案将成为 OpenAI 的一大亮点。

但这一声明被指责为 OpenAI 使用纽约大学数学家 Tristan Buckmaster 和 Anthropic 员工 Levent Alpöge 在该问题上的人工智能辅助工作作为出发点而未能给予他们认可的指控而蒙上阴影。

 OpenAI 否认了这些指控。

目前还不确定 OpenAI 的模型是否利用了 Buckmaster 和 Alpöge 完成的工作，不过 OpenAI 技术人员 Sébastien Bubeck 在新闻发布会上表示，该团队在听到有关 Buckmaster 和 Alpöge 工作的传言后受到启发，开始解决这个问题。

但无论 OpenAI 的模型是否利用了 Buckmaster 和 Alpöge 的研究，这一事件都可能标志着数学史上的一个转折点。

现在，人工智能模型对于在我们这个时代最重要的数学问题上取得进展似乎至关重要，而解决这些问题可能需要只有少数前沿人工智能公司才能提供的资源，而这些公司往往违反支撑大多数数学进步的学术合作规范。

如果这就是我们所走向的未来，那么人类数学家将如何融入其中还不清楚。

OpenAI 声称已经解决的问题被称为纳维-斯托克斯存在性和平滑性问题。

这是克莱数学研究所 2000 年选出的七大千禧年奖问题之一。

解决方案将获得 100 万美元的奖金；在今天之前，仅解决了另一个千年奖问题。

纳维-斯托克斯问题涉及一组方程，这些方程描述了水和空气等流体如何随时间流动。

这些方程广泛应用于流体动力学领域，并且已被证明是强大的，但物理学家和数学家并没有完全理解它们。

特别是，直到今天我们还不知道这些方程在某些条件下是否会分解并预测不可能的事态——例如具有无限速度的流体。

周一，纽约大学的巴克马斯特在社交媒体网站 Mastodon 上发布了一份证明，证明简化版的纳维-斯托克斯方程确实可以被破解——这是解决千年问题的重要一步。

他和 Alpöge 使用 OpenAI 和 Anthropic 的公开模型研究这个问题近一年。

今天，OpenAI 提出了一个证明，表明完整的纳维-斯托克斯方程也可以被打破。

该证明是使用内部模型获得的，该模型的性能远远优于上周才发布的已经令人印象深刻的 Astra 模型。

该公司表示，不打算因解决该问题而获得百万美元奖金。

这些数学成就无疑令人印象深刻，但它们引起的关注远不如对其起源的争议那么关注。

除了证据之外，巴克马斯特还发布了一份文件，详细介绍了他在听到有关 OpenAI 员工工作的谣言并联系其中一位员工后与他们的互动。

据他介绍，OpenAI 员工向他提出了两种可能性：要么他和 Alpöge 可以发布他们的工作，OpenAI 将在第二天发布他们的 Navier-Stokes 解决方案，要么他可以与 OpenAI 合作撰写一篇 Navier-Stokes 论文，但由于 Alpöge 与 OpenAI 最大竞争对手 Anthropic 的关系，将 Alpöge 排除在作者之外。

Buckmaster 还写道，他询问员工，特工是否获得了他和 Alpöge 使用 OpenAI 模型完成的工作记录，但他们否认了这一点；以及 OpenAI 模型是否接受过这些转录本的训练，但他们没有对此做出回应。

 《麻省理工科技评论》联系巴克马斯特征求意见，但在发表前没有收到回复。
