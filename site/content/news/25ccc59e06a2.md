克劳德今天获得了一对新工具：文档和幻灯片。

他们将允许您通过 Claude 聊天创建文档和演示文稿，您可以导出、编辑并与其他用户共享。

Claude 为 Gemini 带来了自己对文档和幻灯片的看法
您现在可以通过 Claude 聊天创建和编辑文档和演示文稿。

作为公告的一部分，Anthropic 还简化了 Claude 聊天的工作方式，将常规聊天和 Cowork 合并为“one Claude”，并可从任何聊天中使用所有 AI 生产力工具。

 Artifacts 和 Claude Design 功能也将通过新的单一界面提供。

根据 Anthropic 的说法，克劳德“现在可以弄清楚任务需要什么，因此可以通过任何对话以及您已有的背景、技能和连接器来实​​现协同工作和设计可以做的事情。

”
Claude Docs 和 Slides 正在推出测试版，与 Claude Design 一起成为 AI 平台生产力工具的一部分。

您可以让 Claude 从任何聊天中生成文档和演示文稿。

您可以要求 Claude 对其创建的任何内容进行更改，或手动进行编辑。

与 Google Docs 一样，Claude Docs 一开始是私人文档，但您可以与其他可以与您同时处理该文档的编辑者共享它们。

包括克劳德在内的合作者可以留下类似于 Google 文档上的评论。

 Anthropic 表示：“您使用 Claude Design、幻灯片或文档制作的任何内容都位于一个可共享链接中，您可以在手机上打开。

”
人们普遍认为 Anthropic 的模型比谷歌的模型更先进，但谷歌的人工智能服务具有与其生产力工具套件原生绑定的优势。

今年早些时候，Google 扩展了 Gemini 在 Google 文档、表格和幻灯片中的作用，提供了文档中的 Gemini 聊天窗口、使用 Gemini 生成和编辑整个文档以及使用 Gemini 创建幻灯片等功能。

 Claude 新增的文档和幻灯片开始缩小 Anthropic 的 AI 平台和 Google 生产力工具之间的差距，让用户不再有理由离开 Claude 聊天而选择其他工具。

“one Claude”更新将在“接下来的几周内”首先向 Web、桌面和移动设备上的 Pro 和 Max 用户推出，稍后将向团队和免费用户推出。

 Anthropic 表示，更新中“没有什么可打开的”，用户也可以继续正常使用 Claude 聊天功能。
