Claude Code 中改进的项目功能允许用户在同一屋檐下运行多个代理，并共享内存、目标以及文件和工件库。

与 Grok Bot 和其他管理 AI 代理组的工具类似，每个项目都有并行运行不同任务的“线程”，并有一个“协调器”指导一切：
Claude Code 重新启动项目以管理云中的多个人工智能代理
项目允许用户控制一组相互协调的 Claude Code 代理。

在底层，每个线程都是一个 Claude Code 云会话，在其自己的分支和存储库副本上工作。

协调器使工作井井有条，但如果任何线程处理相同的代码，则重叠将作为合并冲突解决，就像任何其他 PR 一样。

每个线程都可以在需要时使用子代理、循环和工作流程将其委派的工作进一步拆分为多个部分，以便大型任务可以更快地完成。

用户可以单独与每个线程交互，或者通过主项目聊天监控和更新内容。

发布时，线程在云中运行，但 Anthropic 表示对本地工具和代码的支持“很快”就会到来。

更新后的项目功能从今天开始面向“精选 Claude Pro 和 Max 订阅者”提供测试版，稍后将访问权限扩展到所有 Pro、Max、Team 和 Enterprise 用户，以及 Cowork 和常规 Claude 聊天。
