周日，微软首席执行官萨蒂亚·纳德拉 (Satya Nadella) 加倍强调
他早些时候发出的令人震惊的警告
本月，针对使用人工智能的企业，这次更进一步。

他预测，完全依赖专有人工智能实验室来满足人工智能需求的公司最终将无法生存。

这就是他说的
CNN 的“法里德·扎卡里亚 GPS”。

当扎卡里亚要求纳德拉解释什么构成公司与人工智能模型提供商共享过多信息时，纳德拉表示，企业需要警惕他们移交的所有内容，从数据到提示。

纳德拉呼吁进行这样的设置：“每次使用该模型时，它周围的所有元数据都会由您保留，以便您可以使用所有这些元数据来训练您自己的权重或您自己的开放模型。

” （权重是模型经过训练的参数，本质上是模型的大脑。

纳德拉的观点是：公司应该保留自己的使用数据，以便最终能够构建自己的模型。

）
“我认为，任何没有这种控制权的公司都将不再是一家公司，因为你基本上已经外包了你的思维，”他补充道。

简而言之：纳德拉表示，没有自己的模型的公司，或者没有被称为人工智能网关的人工智能基础设施层，将其提示与模型本身分开的公司，将会遇到麻烦。

他特别希望公司停止依赖人工智能实验室的内置编码工具，即harnesses。

（Anthropic 的 Claude Code 和 OpenAI 的 ChatGPT Codex 就是这样的例子。

）
