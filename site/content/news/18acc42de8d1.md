亚马逊和英伟达的关系越来越近了。

两家公司周三宣布扩大合作伙伴关系，其中包括一项为亚马逊数据中心再增加 200 万个 Nvidia GPU 芯片的协议。

这些 GPU 旨在满足训练和运行 AI 模型的繁重计算需求，包括 Nvidia Blackwell Ultra、Rubin 和 Rubin Ultra GPU。

这些芯片将于 2027 年和 2028 年运往 Amazon Web Services 的数据中心。

这一消息是在英伟达的季度财报电话会议上宣布的，距离亚马逊同意部署仅五个月
超过 100 万个 Nvidia GPU
从今年开始，AWS 基础设施将全面覆盖。

英伟达在一份声明中表示，从那时起，“需求已经超出了预期。

”
两家公司都没有分享财务条款。

目前尚不清楚英伟达的具体回报是多少。

但考虑到GPU单位成本，这笔交易价值数百亿美元。

该公告之所以引人注目，不仅因为其规模和增长速度，还因为它超出了亚马逊购买更多 Nvidia 芯片的范围。

即使亚马逊投资了自己的潜在竞争人工智能芯片，这种情况仍在发生。

Nvidia 周三表示，其技术，包括将数千个 GPU 连接到一个系统中的网络硬件，以及其开放模型、CPU、数据处理软件和机器人平台，也将在 AWS 上进行集成。

两家公司表示，初创公司、企业、人工智能实验室甚至政府的“需求激增”影响了更密切合作的决定。

此次扩大合作伙伴关系之际，亚马逊加大了自己的人工智能芯片研发力度，尤其是 CPU，这是服务器核心的通用处理器。
