使用 Claude Code 进行编程很快将需要更少的人工监督，Anthropic 表示，从 8 月 14 日开始，它会将自动模式设置为 Pro、Max 和 Team 帐户的默认模式。

公司第一
三月份推出了自动模式测试版
，将其视为平衡速度和控制的一种方式。

正如人类解释的那样
周五宣布
，当 Claude Code 处于自动模式时，它不会在每一步都显示要求人类批准的提示，而是会继续进行，除非某个操作被确定为“不可逆转、具有破坏性或针对您的环境之外”。

Anthropic 还表示，在测试中，自动模式比人工审查更安全——在一项针对 1,053 名付费测试人员的研究中，自动模式发现了 89% 的有害行为，而人工审查仅发现了 13.6%。
