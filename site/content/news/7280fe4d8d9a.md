跑道开发
本月早些时候发布的开发者平台，除了 Runway 自己的模型之外，还提供对越来越多的第三方图像、视频和音频模型的 API 访问。

媒体路由器是一种工具，可以根据开发人员是否优先考虑质量、速度或成本来自动为请求选择最佳图像、视频或音频生成模型。

虽然模型路由器在大型语言模型领域变得越来越普遍，但 Runway 表示，这是第一个专门为生成媒体构建的路由器。

Runway 首席产品官 Anthony Maggio 告诉 TechCrunch：“该路由确实符合作为开发者与任何类型的生成媒体模型集成的最简单的一站式商店的整体承诺。

”
此次发布由 TechCrunch 独家分享，标志着 Runway 从人工智能视频初创公司向生成媒体构建公司的基础设施发展又迈出了一步。

通过 Runway Dev，包括 Adob​​e、Cloudflare、ElevenLabs、Expedia、Shutterstock 和 Quora 在内的客户可以使用 Runway 的 API 将媒体生成直接构建到自己的产品中，而不是将用户发送到 Runway 自己的应用程序或网站。

该路由器的推出正值生成媒体模型数量爆炸式增长之际，这使得开发人员评估新版本变得越来越困难和耗时。

通过 Runway Dev 平台，开发人员可以在最新的媒体模型发布时访问它们。
