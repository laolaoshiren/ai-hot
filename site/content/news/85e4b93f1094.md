9 月 15 日，在北京举行的 2026 飞书未来无限大会暨豆包工作开工大会上，飞书发布 8.0 版本，并介绍了与“豆包工作”的原生融合方式。

“经过多年努力，飞书成了最多人喜爱的协同办公平台，同时也是 Agent 最好的工作平台。

”飞书 CEO 谢欣表示，“现在，如果企业需要选择协同办公平台，飞书无疑是最好的选择。

再加上原生融合的企业级 Agent 豆包工作，这将是 AI 时代工作的最佳选择。

”
同日发布的“豆包工作伙伴”，则将智能体的使用场景从个人任务扩展到了团队协作。

目前，这一产品仍处于与企业定向共创阶段，尚未全面向客户开放。

这次更新的重点，是让智能体能够在企业现有的协作环境中获取信息、调用工具并执行任务。

飞书 8.0 将消息、文档、多维表格、日历、会议、云盘及审批等能力进一步开放给智能体，使其能够在授权范围内参与具体工作流程。

据谢欣介绍，飞书 8.0 对 Agent 的适配主要体现在三个方面：让人与 Agent 自然协作、Agent 和人一样使用各类产品、企业管理 Agent 像管人一样权限清晰、安全可控。

在此次功能更新中，比较有意思的是，用户可以像邀请成员一样，将智能体加入群聊。

例如在群聊中，用户搜索名字即可将 Agent 拉进群，多个 Agent 也可在群组中互相协作。

用户可以让它们在飞书撰写文档、操作多维表格、安排日程待办、参与会议、查阅云盘和妙记、发起审批流程。

人能在飞书里完成的工作，Agent 几乎都能完成。

飞书此前推出的命令行工具 CLI，为智能体提供了调用平台功能的途径；按飞书在会上公布的数据，通过 CLI 开放的功能点已从今年 3 月的 247 个增至 767 个。

飞书公开的 CLI 使用指南也列出了消息、文档、日历、妙记和多维表格等可接入的工作对象。

能操作的范围扩大后，权限管理也成为产品设计的一部分。

据称，以员工身份使用的智能体沿用该员工的访问权限：员工无权查看的信息，智能体也不能获取。

管理员则可以管理智能体的使用情况、设置用量上限，并限制高消耗模型和使用场景。

对企业而言，智能体能否准确完成任务固然重要，它执行了哪些操作、访问了哪些数据、消耗了多少资源，同样需要能够查询和控制。
