尽管 Ellison 声称“Oracle 没有编写”自己的代码，但 Oracle 仍禁止 OpenJDK 中人工智能生成的代码
●4天前
Oracle 以安全和知识产权风险为由，禁止在 OpenJDK 贡献中使用人工智能生成的代码。

这位开源 Java 项目管理员表示，开发人员可以私下使用 LLM 来调试和审查代码，但不能将人工智能生成的材料提交到存储库、拉取请求或其他项目渠道。

该政策与甲骨文的内部做法形成鲜明对比。

联合创始人拉里·埃里森 (Larry Ellison) 最近宣称人工智能模型现在可以编写 Oracle 的代码，而联合首席执行官迈克·西西利亚 (Mike Sicilia) 则认为人工智能工具使较小的工程团队能够更快地交付。

甲骨文今年将投资 700 亿美元用于数据中心扩建。

这一支出热潮促使信贷机构标准普尔将甲骨文的评级下调至 BBB-，比垃圾级高一级，理由是投资回报不确定。
