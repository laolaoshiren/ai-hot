1Password 为 Claude 推出了新的浏览器集成，允许 Anthropic 聊天机器人访问存储的安全凭证，例如用户名和密码。

据 1Password 称，1Password for Claude 功能意味着用户可以授权 Claude 代表他们完成多步骤任务，例如预订旅行和管理在线帐户，而无需手动输入登录凭据，但实际上不会将您的安全信息暴露给 Anthropic 的人工智能模型。

Claude 现在可以为您使用您的 1Password 凭据
Anthropic 的人工智能实际上无法看到你的密码，但现在它可以不间断地自动执行更多任务。

Anthropic 的人工智能实际上无法看到你的密码，但现在它可以不间断地自动执行更多任务。

1Password 开发的新“零暴露安全框架”使这一切成为可能，该框架的工作原理是通过 Claude 代理无法查看的安全通道注入每项任务所需的凭据。

这意味着，虽然 AI 可以被授予使用您存储的详细信息的权限，但它实际上无法看到您的密码或 MFA 一次性代码。

Claude 访问权限按任务授予，1Password 表示其用户可以通过单个生物识别提示批准或拒绝每个请求。

这仍然是一个工作流程中断，但与暂时接管登录帐户相比，不那么麻烦。

作为预防措施，1Password 表示，它还会在每次自动填充后扫描页面，以确保在将控制权返回给 Claude 之前，表单提交中的任何内容都不会暴露。

1Password 在其新闻稿中表示：“人工智能代理控制浏览器的那一刻，1Password 就会自动锁定，仅限制对当前任务明确授予的凭据的访问。

” “1Password 保险库中没有其他内容可访问。

”
1Password for Claude 现已可供 Mac 上的 1Password 用户使用，涵盖企业、家庭和个人计划。

使用该功能需要 1Password 桌面应用程序和浏览器扩展，以及 Claude 桌面应用程序和浏览器扩展。

您可以在 1Password 的保管库中存储各种安全信息，包括密码、密钥、2FA 代码、API 令牌以及地址和财务详细信息等个人信息。

 1Password 没有具体说明 Claude 将能够访问哪些凭据，但目前似乎仅限于与登录相关的详细信息 - 该公司表示，对支付卡和身份详细信息的支持将在发布后的某个时候提供。
