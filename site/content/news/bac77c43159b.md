整理 ｜华卫
刚刚，GPT-5.6 官宣大降价，降幅最高达 80%。

即日起，Luna 和 Terra 的更低价位已体现在 Codex 和 ChatGPT Work 的使用量计费中。

其中，入门款 Luna 价格下调 80%，定价为每百万输入 token 0.20 美元，每百万输出 token 1.20 美元。

Terra 价格下调 20%，定价为每百万输入 token 2 美元，每百万输出 token 12 美元。

Luna 相比一年前的前沿模型，其性能相当，每项任务的成本约为其 6 美分，速度却快了近九倍。

在专业工作中（以 Agents' Last Exam 衡量），Luna 的表现优于 Fable 5，且每项任务的成本估计降低了近 99%。

Sol 定价保持不变，但他们在 API 中引入了快速模式，以取代之前的优先级处理模式。

据悉，API 中 GPT-5.6 Sol 的快速模式可提供高达标准处理速度 2.5 倍的性能，价格也翻了一番，但智能水平不变。

OpenAI 表示，还将 ChatGPT 应用和 Codex CLI 中的 Auto-review 从 GPT-5.4 升级到 GPT-5.6 Luna。

结合 Luna 的新价格，预计 Auto-review 的成本将降低约 10 倍，使智能体工作流更具成本效益。

据称，这次降价是 GPT-5.6 自身运行效率提升后的回馈。

GPT-5.6 带来的效率提升，源于其在技术栈各个层面持续改进，涵盖研究、推理以及智能体框架。

具体体现于，通过改进生产环境 GPU 内核，服务成本降低了 20%；通过改进推测性解码，token 生成效率提高了 15% 以上。
