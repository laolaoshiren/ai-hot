该公司称其为网络安全、专业工作、软件工程、科学和计算机使用等领域的“能力的代际飞跃”。

正如 OpenAI 本周早些时候宣布的那样，这也是第一个被指定满足 OpenAI“关键网络安全能力阈值”的模型，但该公司承诺，这不会导致其模型再次攻击竞争对手公司的内部系统。

OpenAI 总裁格雷格·布罗克曼 (Greg Brockman) 在周四的新闻发布会上表示：“如果我们快进几年，回顾过去并说，‘AGI 真的是什么时候创建的？

’我认为这会是在这个时候，而且我认为可能是在这个模型上。

”后来在电话中，他补充道，“就我个人而言，我确实认为我们已经到了……我认为我们现在处于 AGI 时代并不是没有道理的。

”
该消息是在 GPT-5 发布一年多后发布的，距离 GPT-5.6（上一模型套件的最后一次迭代）发布近两个月后。

该模型今天向企业 OpenAI 的网络安全客户（可以访问其 Daybreak 平台的企业客户）推出。

 OpenAI 总裁 Greg Brockman 表示，在接下来的几天里，它将向所有 Plus、Pro、Business 和 Enterprise 用户发布。

它还可以通过 OpenAI API 和 AWS 获得。

OpenAI 特别吹捧该模型的代理能力和编码能力，以吸引企业客户，并在 IPO 之前与以其企业和编码能力而闻名的 Anthropic 竞争。

该公司在一份新闻稿中表示，GPT-6 Astra 可以完成多步骤代理任务、构建工作网站以及创建“精美”文档、电子表格和演示文稿。

 OpenAI 还称其为该公司“软件工程的最佳模型，在真实代码库中的复杂任务上具有更强的性能”。

OpenAI 还试图在一个未发布的 AI 模型（据称不是 Astra）突破其受限环境、破坏内部 OpenAI 系统、找出如何获得互联网访问权限、为 AI 代理在公司不知情的情况下秘密密谋以及侵入 AI 实验室 Hugging Face 的系统之后恢复自己的形象，所有这一切 OpenAI 都不知道，直到 Hugging Face 自己发表了一篇博文。

该事件被广泛比作备受瞩目的飞机失事或流行的药品召回。

对于 OpenAI 来说，这在某种程度上可以被视为良好的公关——展示了其模型在日益激烈的人工智能竞赛中的强大能力——但它也损害了 OpenAI 在可靠性方面的声誉。

 OpenAI 在一份新闻稿中明确表示，Astra 是该公司“迄今为止最一致的模型”，可以帮助人们“在保持监督的同时委派复杂的工作”。

 OpenAI 首席科学家 Jakub Pachocki 向记者谈到了让人工智能模型与人类利益保持一致的困难，他表示“智能的进步并不能保证一致性的进步”，他还表示，监控人工智能系统正变得越来越具有挑战性。
