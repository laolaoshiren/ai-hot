我们刚刚与 OpenRouter 建立了合作伙伴关系，这使我们能够提供两项新功能：
- 首先，您的项目可以通过我们的AI网关使用OpenRouter上的任何模型。

这意味着，如果您自己的网络应用程序向最终用户提供基于人工智能推理的功能，那么您现在可以选择更广泛的模型来满足任何任务和预算。

- 其次，我们正在扩展可通过 Agent Runners 使用的前沿编码模型的选择。

 Agent Runners 是 Netlify 中的聊天提示框，可让您从头开始构建新项目或迭代现有项目。

现在的模型选择包括最近大肆宣传的开放模型，例如 Kimi K3、GLM 5.2 和 DeepSeek V4，可供所有人使用。

我们将其称为 Agent Runners，因为我们在内部运行完整的编码代理，而不是精简的代理。

到目前为止，我们已经支持 Claude Agent、OpenAI Codex 和 Gemini CLI，它们经过优化可以运行这些提供商的模型。

我们为这些代理提供额外的技能以及当前项目的背景信息，以便代理能够准确地知道哪些 Netlify 功能可供使用（例如 Netlify 数据库、AI 网关或身份）、何时使用以及如何使用。

但为了有效地驱动各种新模型，我们添加了流行的开源 OpenCode 作为代理的新选择。

但随着选择的增多，不可避免的问题也随之而来：我如何知道哪种型号适合我？

我是否错过了一些物质上更好或更具成本效益的东西（这样我就可以用我的学分做更多的事情），或者像互联网上所说的那样会让我大吃一惊？

这些天有很多 FOMO 现象。

为了向您提供一些见解，以下是我们在一系列模型中运行相同提示时了解到的信息……所有这些现在都可供您在 Netlify 上使用。

您可以在我们创建的带有完整报告的网站上看到我们测试的所有模型的结果。
